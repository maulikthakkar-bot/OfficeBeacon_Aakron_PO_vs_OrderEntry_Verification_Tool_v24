Supported Bill-To companies

The tool recognises the Bill-To company from the PO and then checks the Order Entry “Ordered By / Bill To” (customer no., company, address, phone) and reads the PO with that company’s own layout.

#Bill-To companyPO layout readBill-To check on Order Entry
  • A PO from a company that is not in this list is still read with the universal reader, but every row must be checked against the PDF.
  • To add a company, send its PO and Order Entry PDFs – it is added to this list for everyone.
Plant locations (item → Site)

For every customer: the item # on the PO is looked up in this list and the Site on the Order Entry packing-slip page must be the plant that makes it (T, N, F or Outsource). It is shown as the Warehouse row in section 2 of every comparison (“Plant T” on the PO side, “Site T” on the Order Entry side).

When the Order Entry customer no. (e.g. 116550-0) and every item on the order are on this list, the set-up charge on the PO and on the Order Entry must equal the list amount (a $0 entry means no set-up charge). If the customer is on the list but an item is not, nothing is checked. A row also appears if the order date is outside the list's dates.

    Multi-supplier

    Add each supplier once. The selected supplier is used when searching for the detected item number. Supplier settings are saved in this browser.

    Add / edit supplier website
    Use {item} where the item number should be inserted. If blank, the tool opens a web search limited to this supplier's website.

    To share the same supplier directory with all employees, export the supplier list once and share the JSON file with the team. Each employee imports it into their browser. Browser-saved supplier settings are not automatically shared between computers.

    Connect a supplier website

    Select a supplier, then use Connect Website to open its website. Search Item Number opens a supplier-specific product search in a new browser tab. This does not sign in to supplier accounts or create a private API connection.

    Customer profiles

    Customers are recognised automatically when one of the “detect by” words appears on the PO. Customers without a dedicated layout are read with the universal reader. Add any customer, plus standing instructions that must always be on the Order Entry.

    Scanned / image-only PDFs have no text layer and need OCR first. Always review the original documents before releasing an order.
